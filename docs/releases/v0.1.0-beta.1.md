# OpenNest v0.1.0-beta.1 (Akses awal)

Status: source-only preview. Not a hosted beta. Not a Stage E release.

OpenNest adalah ruang kerja digital lokal-first untuk file, catatan, folder, tag,
dan pencarian. Rilis ini adalah snapshot source code untuk dicoba secara lokal
dan diuji sebelum ada hosted beta.

## Yang bisa dicoba

- Library, upload file, folder, tag, dan preview file.
- Catatan Markdown dengan autosave, draft recovery, dan export per catatan.
- Pencarian lokal dan link antar catatan.
- Backup lokal, validasi, import, dan restore.
- PWA yang bisa dipasang dan dibuka offline setelah build.
- Antarmuka Bahasa Indonesia dan Inggris.
- Enkripsi konten workspace opsional. Belum direview secara independen.
- Konsol AI BYOK opsional dengan consent.
- Ekstensi sideload lokal dengan sandbox read-only. Belum direview secara
  independen.

## Cara menjalankan

Butuh Node.js 24 atau lebih baru, npm 10 atau lebih baru, dan Git.

```bash
git clone https://github.com/ryaa-Lz/OpenNest.git
cd OpenNest
git checkout v0.1.0-beta.1
npm ci
npm run build
npm start
```

Buka `http://localhost:3000`.

Panduan lengkap, termasuk Termux, port, dan backup, ada di
[`docs/run-locally.md`](https://github.com/ryaa-Lz/OpenNest/blob/v0.1.0-beta.1/docs/run-locally.md).

GitHub menyediakan arsip source ZIP dan tarball untuk tag ini. Tidak ada binary
asset tambahan dalam rilis ini.

## Batasan

- Tidak ada link hosted, akun OpenNest, atau server OpenNest dalam rilis ini.
- Tidak ada sync cloud, multi-device, atau alur kolaborasi di browser.
- Tidak ada registry atau marketplace ekstensi.
- Dokument Q&A dan MCP belum punya surface pengaturan di aplikasi.
- Data tersimpan di browser. Backup sebelum menghapus site data atau berganti
  browser.
- Ini bukan rilis Stage E. Gate Stage D dan Stage E masih terbuka.
- Belum ada review keamanan independen. Jangan pakai sebagai satu-satunya salinan
  data penting atau untuk data sensitif.

Tidak ada klaim E2EE, kerahasiaan AI, keamanan sandbox ekstensi, atau isolasi MCP
dalam rilis ini. Baca
[`docs/early-access.md`](https://github.com/ryaa-Lz/OpenNest/blob/v0.1.0-beta.1/docs/early-access.md)
dan [`SECURITY.md`](https://github.com/ryaa-Lz/OpenNest/blob/v0.1.0-beta.1/SECURITY.md).

## English summary

This is the source-only `v0.1.0-beta.1` early access preview. There is no hosted
beta, no OpenNest account, and no OpenNest server in this release. Run it locally
with Node.js 24:

```bash
git clone https://github.com/ryaa-Lz/OpenNest.git
cd OpenNest
git checkout v0.1.0-beta.1
npm ci
npm run build
npm start
```

Open `http://localhost:3000`. Your workspace stays in browser storage. Export a
backup before clearing site data or changing browsers.

This is not a Stage E release. Stage D and Stage E gates remain open. No E2EE, AI
confidentiality, extension sandbox security, or MCP isolation claim is made. Do
not use this preview as the only copy of important data or for sensitive
information. Licensed AGPL-3.0-only.
