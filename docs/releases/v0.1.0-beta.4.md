# OpenNest v0.1.0-beta.4

This release carries the Android splash fix from beta.3 and shows encryption
setup progress as soon as setup starts. It does not change the supported product
surface: OpenNest remains a source-only early access preview, and the web
application and PWA are the supported platforms.

## Changed

- Encryption setup opens the migration progress screen immediately instead of
  waiting for key derivation to finish. The screen keeps the Cancel setup action
  available.

## Fixed

- The Android release workflow now reads release notes from the checked-out
  repository, so published releases include their notes.
- This release includes the beta.3 fix that dismisses the Android launch splash
  screen and removes the leftover splash strip above the app header.

## Android personal build

- Capacitor 8 wrapper in `apps/mobile` with a committed Android project.
- Static Next.js export bundled into the APK, served from `https://localhost`.
- Offline launch after install. The Android build does not register a service
  worker and unregisters an existing one.
- Query-parameter routes for entity details, with legacy URL redirects.
- Native export and share through the Android share sheet.
- Safe-area support, edge-to-edge layout, system-bar theme synchronization,
  keyboard resizing, and Android back handling.
- Cleartext traffic and Android backup are disabled. Only the INTERNET
  permission is requested.
- Release signing by GitHub Actions, with the APK published on the GitHub
  release.

The package id is `app.opennest`. Debug builds use `app.opennest.debug`.

## Install

Download `OpenNest-0.1.0-beta.4.apk` from the release assets and open it on the
phone. Installing over beta.3 keeps the local workspace because the package id
and signing key are unchanged. The first install may require allowing installs
from the file manager or browser.

Uninstalling OpenNest deletes its local workspace. Export a backup first.

## Known limitations

- This is an unsupported personal package, not a Play Store release.
- No in-app updates. Install newer APKs manually.
- Local HTTP AI providers are blocked by the cleartext policy.
- The Stage D security review, external cryptographic review, and E2EE claim gate
  remain open. This release does not add any security or confidentiality claim.

See `docs/android.md` for build and signing details.
