# Run OpenNest locally

This guide runs the `v0.1.0-beta.1` source preview on your own machine. No
OpenNest account or server is required.

## Requirements

- Node.js 24 or newer. The repository pins Node 24 in `.nvmrc`.
- npm 10 or newer.
- Git.
- A modern browser.

Check the versions before installing:

```bash
node --version
npm --version
git --version
```

## Get the source

```bash
git clone https://github.com/ryaa-Lz/OpenNest.git
cd OpenNest
git checkout v0.1.0-beta.1
```

## Install and build

Use `npm ci`, not `npm install`, so the lockfile is respected:

```bash
npm ci
npm run build
```

## Start the app

```bash
npm start
```

Open `http://localhost:3000`.

If port 3000 is already in use, pass another port:

```bash
npm start -- -p 3001
```

Then open `http://localhost:3001`.

Stop the app with `Ctrl+C`.

## Development mode

To work on the source instead of running the production build:

```bash
npm run dev
```

The development server also opens on `http://localhost:3000` by default.

## Data and backups

The app stores your workspace in the browser's IndexedDB for the origin you use.
If you switch from `localhost:3000` to `localhost:3001`, you get a separate
workspace.

Clearing site data deletes the workspace stored for that origin. Export a backup
from the app before clearing site data, changing browsers, testing restore, or
resetting the workspace. Keep a copy outside the browser.

The service worker is generated by `npm run build`. Offline mode and PWA
installation need that build. `npm run dev` is for development, not for testing
the production service worker.

## Android and Termux

Do not run the checkout from Android shared storage. Use the Termux home
directory, for example:

```text
/data/data/com.termux/files/home/opennest
```

See `docs/development.md` for the filesystem and native module limitations on
Android.

## Troubleshooting

### Node version error

The project requires Node 24 or newer. Check with `node --version`. If you use a
version manager, select Node 24 before running `npm ci`.

### Install fails on Android

Move the checkout off shared storage and remove the partial install:

```bash
rm -rf node_modules
npm ci
```

### Port already in use

Start on another port with `npm start -- -p 3001`.

### Blank page or stale service worker

Stop the app, run `npm run build` again, start it, then reload the browser. If the
problem continues, clear site data for the local origin and restore a backup.
Clearing site data deletes the local workspace.

### Data seems missing

Confirm that the origin is exactly the same, including the port. Data for
`localhost:3000` is not shared with `127.0.0.1:3000` or `localhost:3001`.
